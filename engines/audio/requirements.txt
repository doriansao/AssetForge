# Audio engine dependencies. Install order matters; see docs/SETUP.md.
#
# The torch / xformers / numpy trio is pinned rather than floated, and the pins
# are not arbitrary:
#
#   torch 2.4.0 + xformers 0.0.27.post2   the only pairing with prebuilt Windows
#                                          wheels on the cu121 index. Newer
#                                          xformers has no wheel for this
#                                          platform and building from source
#                                          fails on Windows path length limits
#                                          inside its vendored flash-attention.
#   numpy < 2                              torch 2.4.0 was built against numpy
#                                          1.x. With numpy 2 installed, torch
#                                          raises "Numpy is not available" from
#                                          inside audiocraft's sampling loop.
#   av 18.1.0                              audiocraft's own pin has no wheel for
#                                          Python 3.11 on Windows and fails to
#                                          compile, so audiocraft is installed
#                                          with --no-deps and av supplied here.
